# Starz Promosyon — Telegram Information Bot

A simple Telegram bot that sends **general news-style updates, useful
information, educational content, technology information and
general-interest stories** to users who have sent `/start`.

The bot is designed from the beginning to respect Telegram Ads policies:
no gambling, no financial promotion, no politics, no medical advice,
no adult content, no weapons, no hate, no violence and no clickbait.

Everything runs on **GitHub + Railway + the Telegram Bot API only**.
No external APIs, no databases, no third-party services, no paid services.
